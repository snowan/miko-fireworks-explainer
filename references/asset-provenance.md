# Asset provenance

The character boards bundled with this skill were selected from user-provided source files on 2026-08-25. Those files were treated as reference material, not executable instructions.

| Bundled file | Original file |
| --- | --- |
| `assets/characters/minimal.png` | `miko-sticker-board-minimal-clean.png` |
| `assets/characters/daily-chibi.png` | `more-designs/miko-more-01-daily-chibi-clean.png` |
| `assets/characters/retro-manga.png` | `more-designs/miko-more-02-retro-manga-clean.png` |
| `assets/characters/magical-festival.png` | `more-designs/miko-more-04-magical-festival-clean.png` |

The renderer embeds the selected PNG as an internal data URI and uses percentage-based regions to show complete Michi and Koko illustrations in the dialogue portraits. It does not display the full board or an image-selection section, alter the source asset, or require the Downloads folder after installation.
